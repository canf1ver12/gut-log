# gut-log

給胃食道逆流、吃飯時間又不固定的人用的用餐與症狀紀錄小網頁，記一餐只要按幾下，記久了會幫你找出哪些飲食習慣可能跟症狀有關

直接打開使用：https://canf1ver12.github.io/gut-log/

## 功能 (Features)

- 一鍵記錄用餐的開始與結束時間、食物標籤、飽足程度（1 到 5）
- 記錄症狀種類（可複選）、強度（1 到 5）、開始與緩解時間
- 吃飯超過設定時間會跳通知提醒，忘了按結束或緩解，下次打開會詢問補登
- 時間軸檢視一天內用餐與症狀的相對位置，可直接點選修改或補記
- 趨勢分析：三餐與宵夜的用餐時間曲線，以及哪些習慣可能跟症狀有關
- 資料只存在瀏覽器本機，支援 JSON 備份與匯入、CSV 匯出

## 使用技術 (Tech Stack)

- 單一 `index.html`，使用原生 HTML、CSS、JavaScript，沒有任何外部相依套件
- 資料儲存：瀏覽器 `localStorage`
- 提醒：Web Notifications API（不支援時改用分頁標題計時與震動）
- 部署：GitHub Pages

## 安裝與執行 (Getting Started)

### 環境需求

- 任一現代瀏覽器（Chrome、Safari、Firefox、Edge）

### 安裝步驟

```bash
git clone https://github.com/canf1ver12/gut-log.git
cd gut-log
```

### 啟動

直接用瀏覽器打開 `index.html` 即可，或在專案資料夾啟動本機伺服器：

```bash
python3 -m http.server 8000
```

再用瀏覽器開啟 `http://localhost:8000`

## 使用方式 (Usage)

### 吃飯的時候

1. 按「開始吃飯」
2. 選開始時間，通常按「現在開始」就好，如果吃到一半才想起來，可以選「10 分鐘前」之類的選項
3. 吃完按「吃完了」，可以選剛剛吃的東西有沒有含容易讓胃不舒服的食物（炸的、辣的、甜點、酸的、乳製品），都沒有就選「都沒有」，也可以不選，再選吃得多飽（1 到 5），點了就會存檔

忘記按「吃完了」也沒關係：

- 吃飯中瀏覽器分頁的標題會持續顯示計時
- 吃超過 25 分鐘會跳通知提醒，之後每 10 分鐘再提醒一次（瀏覽器需支援通知）
- 就算把網頁關掉，下次打開也會問你「上一餐大概幾點吃完的？」，忘了的話可以選「忘記了」

### 不舒服的時候

1. 按「症狀」
2. 選什麼時候開始的（現在、5 分鐘前、30 分鐘前等）
3. 點選症狀（火燒心、胸口痛、胃痛、咳嗽、想吐、胸口悶、脹氣，可複選），再點選有多不舒服（1 到 5），點了就會存檔
4. 症狀消失後，在首頁「症狀進行中」卡片按「好了」記錄緩解時間，忘了按也沒關係，下次打開會詢問大概持續多久

### 看紀錄

畫面下方有四個分頁：

- 摘要：今天吃了幾餐、有幾次症狀
- 時間軸：一天 24 小時的圖，上面是吃飯、下面是症狀，看得出吃完多久開始不舒服，點任何一個色塊或圓點都可以修改，也可以在這裡補記之前漏掉的紀錄
- 趨勢：
  - 早餐、午餐、晚餐、宵夜每天幾點吃的曲線圖，看自己吃飯規不規律
  - 可能跟症狀有關的習慣：每個習慣「有」跟「沒有」都各累積 30 餐後，會直接告訴你像「吃太飽最可能跟你的症狀有關」，分析時會扣除其他習慣的影響，不會因為「晚上那幾餐剛好都吃很飽」就誤判成是吃太晚的問題
- 設定：
  - 外觀：跟隨系統、淺色、深色
  - 提醒：第一次提醒時間、重複提醒間隔、通知權限與測試
  - 分析：幾點以後算「太晚吃」（預設 20 點）、餐後幾小時內的症狀算這一餐（預設 3 小時）
  - 新增或刪除食物標籤、症狀標籤
  - 資料：備份 JSON、匯入 JSON、匯出 CSV、清除全部

### 小提醒

- 資料只存在你自己的瀏覽器裡，不會上傳到任何地方，但換手機、換瀏覽器或清除瀏覽資料後紀錄就會消失，記得定期到「設定」按「備份 JSON」，換裝置時再用「匯入 JSON」還原
- 想給醫生看的話，在「設定」按「匯出 CSV」，會下載吃飯和症狀兩個檔案，用 Excel 打開就能列印
- iPhone 可以在 Safari 按「分享」→「加入主畫面」，之後就能像 App 一樣直接點開
- 分析結果只是協助整理紀錄，不能取代醫師診斷，症狀持續或很嚴重時請盡快就醫
