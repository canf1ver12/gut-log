# gut-log 🍚

如果你也有胃食道逆流，吃飯時間又很不固定，常常搞不清楚到底是吃太晚、吃太飽，還是吃了什麼才不舒服，需要一個簡單的紀錄用餐時間及內容以及症狀的工具就可以使用這個小網頁：**記一餐只要按幾下**，記久了它會幫你看出哪些習慣可能跟症狀有關。

👉 **直接打開用**：https://canf1ver12.github.io/gut-log/

不用註冊、不用登入，手機電腦都可以。

---

## 用法

### 吃飯的時候

1. 吃飯時，按 **「開始吃飯」**
2. 選開始時間，通常按 **「現在開始」** 就好，如果吃到一半才想起來，可以選「10 分鐘前」之類的
3. 吃完按 **「吃完了」**，選單會跳出一些標籤選項，可以選擇剛剛吃的食物是否有含一些容易讓胃不舒服的東西（炸的、辣的、甜點...，也可以選擇「無」的標籤，或不選擇標籤），再選吃得多飽（1 到 5），網頁就會記錄下這筆資料

忘記按「吃完了」也沒關係：

- 吃飯中瀏覽器分頁的標題會一直顯示計時
- 吃超過 25 分鐘會跳通知提醒你，之後每 10 分鐘提醒一次（若瀏覽器支援通知）
- 就算把網頁關掉，下次打開也會問你「上一餐大概幾點吃完的？」，忘了的話也可以選「忘記了」

### 不舒服的時候

1. 按 **「症狀」**
2. 選什麼時候開始的（現在、5 分鐘前、半小時前...）
3. 點症狀（火燒心、胸口悶、脹氣...，可以複選），再點有多不舒服（1 到 5），網頁就會記錄下這筆資料
4. 症狀消失以後，可以在首頁一張「症狀進行中」的卡片中點選 **「好了」** 記錄症狀消失的時間。忘了按也沒關係，下次打開會順手問你大概持續多久

### 看紀錄

下面有四個分頁：

- **摘要**：今天吃了幾餐、有幾次症狀
- **時間軸**：一天 24 小時的圖，上面是吃飯、下面是症狀，看得出吃完多久開始不舒服。點任何一個色塊或點都可以修改，也可以在這裡補記之前漏掉的
- **趨勢**：
  - 早餐、午餐、晚餐、宵夜每天幾點吃的曲線圖，看自己吃飯規不規律
  - **可能跟症狀有關的習慣**：記滿一段時間後（每個習慣「有」跟「沒有」都要各 30 餐），會直接告訴你像「吃太飽最可能跟你的症狀有關」。它會把其他習慣的影響扣掉，所以不會因為「晚上吃的那幾餐剛好都吃很飽」就誤會成是吃太晚的問題
- **設定**：調提醒時間、新增食物或症狀標籤、深淺色切換、匯出資料

## 小提醒

- **資料只存在你自己的瀏覽器裡**，不會上傳到任何地方，別人也看不到。但也代表換手機、換瀏覽器或清除瀏覽資料，紀錄就不見了，記得偶爾到「設定」按 **「備份 JSON」**
- 想給醫生看的話，在「設定」按 **「匯出 CSV」**，會下載吃飯跟症狀兩個檔案，用 Excel 打開就能印
- 用 iPhone 的話，可以在 Safari 按「分享」→「加入主畫面」，之後就像 App 一樣點開
- 分析結果只是幫忙整理紀錄，不能取代醫生。症狀持續或很嚴重，建議立即就醫
